# 助手预设启动与工具状态排查

## 群友聊天与管理员任务

助手模式中的普通群友使用单独的只读聊天通道；其请求不包含可执行工具，也不会携带 `toolChoice`。管理员任务继续沿用当前聊天的授权与 DSH 原生审批。不要为了解决群友无回复，把普通群友加入管理员名单。

## 预设尚未就绪

DSH 刚启动时，本项目连接可能已建立，而 `wechat-assistant` 等预设仍在注册。遇到未注册的预设时，插件等待 1 秒后只重试一次预设解析。该步骤在创建会话、写入新任务及调用模型之前完成，不重试已经执行的工具。

仍未就绪时返回 `AGENT_PRESET_NOT_READY`。等待 DSH 完成加载后可以再次发送任务；仍持续失败时，在 WeChatAgent 准备连接配置，然后从托盘完整退出并重开 DSH，检查预设插件是否启用。权限、模型凭据或其他错误不会被当成预设启动问题反复重试。

已创建任务的同批次重试仍返回原任务；查询状态、取消任务不依赖预设重新注册。等待期间如管理员权限或微信账号变化，新任务会重新校验，不能使用之前的授权继续执行。

## 模型说“没有权限”

助手预设要求以本轮真实工具、本机授权及原生审批为依据。过去聊天中的能力声明不是当前权限证明。需要工具的工作先实际调用，再依据结果说明；失败时区分未授权、等待审批、路径错误、服务未就绪等具体原因。普通聊天不必调用工具。

更新这段预设规则后，需要重新准备连接配置并完整重开 DSH。更换人格不会取消工具权限检查，也不会让普通群友获得管理员能力。

## 搜索与表情诊断

自建搜索服务的调用超时设置见 [网页搜索说明](WEB_SEARCH.md)。

本机找不到表情副本且未允许 CDN 下载时，日志保留 `IMAGE_STICKER_LOCAL_COPY_UNAVAILABLE`，并增加 `reason=STICKER_CDN_DISABLED setting=wechat.media.allowStickerCdn`。如希望允许补充下载，在“表情包 → 来源和搜索”开启“允许从腾讯下载缺失的表情包”，保存后重试。默认不会自动开启，也不会在日志输出下载链接、密钥或聊天内容。
